# 🚲 Bike Price Prediction - End-to-End Machine Learning Project

## 📌 Project Overview

This project builds an end-to-end Machine Learning pipeline to predict the price of used bikes using features like mileage, power, engine capacity (CC), kilometers driven, ownership, and location.

The dataset contains real-world messy data, requiring proper cleaning, preprocessing, and feature engineering.

---

## 🎯 Objective

* Clean and preprocess raw data
* Perform Exploratory Data Analysis (EDA)
* Engineer useful features
* Train multiple ML models
* Evaluate and optimize model performance

---

## 📂 Dataset Features

* model_name
* model_year
* kms_driven
* owner
* location
* mileage
* power
* price (target variable)

---

## ⚙️ Workflow

1. Data Cleaning
2. Feature Engineering
3. Exploratory Data Analysis
4. Model Building
5. Model Evaluation
6. Hyperparameter Tuning

---

## 🤖 Models Used

* Linear Regression
* Random Forest
* Gradient Boosting

---

## 📊 Evaluation Metrics

* MAE
* RMSE
* R² Score

---

## 📈 Key Insights

* New bikes have higher prices
* Higher CC increases price
* More kms driven reduces price
* Brand impacts pricing
